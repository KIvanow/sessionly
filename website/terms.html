1. The Services and the Software

1.1 What Sessionly is

Sessionly is a ledger of AI coding agent sessions. A program on a developer's machine records what coding agents such as Claude Code, Cursor and Grok were asked, which tools they ran, which files they changed and what it cost, and measures how much of what they wrote is still there later. It can upload a record of each session to a Sessionly server, which shows the same figures for a team. The Hosted Service is my installation of that server, which you use through your account.

5. What the Figures Are and Are Not

Sessionly's value is in its numbers, so this section states plainly what they do and do not show.

  • Cost is a measurement, not an invoice. Where a coding agent records its own cost, Sessionly reports it; elsewhere it estimates cost from token counts and the model makers' published prices, and marks the result as an estimate. Prices change, some usage does not appear in any transcript, and a subscription is not billed by the token. For some agents the figure covers only part of a session, and Sessionly says which part. Your provider's bill is the authoritative record of what you spent.
  • The rewrite rate measures survival, not quality. It counts how many of the lines an agent added are still in the file. Code is rewritten for reasons that have nothing to do with how it was written, and a session that just ended scores 100%.
  • The agent share of a pull request is a floor. A line counts as an agent's only when an uploaded session added it; people without Sessionly, sessions uploaded without line hashes, changes made by shell commands and generated files all count as not an agent's. Lines are matched by short hashes, so a common line can match by coincidence.
  • Comparisons between models, agents and people are descriptions, not rankings. Harder work goes to stronger models and to more experienced people, and small samples say little.
  • Identity is a label. The name and email on a session come from git configuration on the machine and are not verified. On a server, uploads are filed under the owner of the token that sent them.
  • Coverage depends on the agents. Sessionly reads what the coding agents record. They change their formats without notice; an update to an agent may stop Sessionly from seeing some or all of its sessions until Sessionly is updated.

Accordingly, you should not use Sessionly's figures as the sole basis for a decision about a person's employment, pay or performance, and I make no warranty that any figure is complete or accurate (Section 12).
