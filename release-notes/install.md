## Install

- From crates.io, with Rust 1.89 or later: `cargo install sessionly`.
- Or a binary from the files below: Linux (statically linked) and macOS, for x86_64 and arm64,
  each as `sessionly-<target>.tar.gz`, with their SHA-256 checksums in `SHA256SUMS`. Unpack it
  and put `sessionly` on your `PATH`.
- From an earlier release: `sessionly update`.

Then `sessionly install` adds the capture hooks. More in the
[README](https://github.com/KIvanow/sessionly#install).
