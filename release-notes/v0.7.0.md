Sessionly records what coding agents did — Claude Code, Codex, Cursor and Grok, on a machine or in
the cloud — in one session record, and says per pull request what it cost and how many of the
agent's lines survived review. Site and live demo: [sessionly.dev](https://sessionly.dev/).

## What changed since 0.6

- **The cost of a pull request is what was spent on it.** It is the cost of every session that
  gave it lines, review rounds included, and it still counts when review takes those lines out.
  Before, it was the cost of the lines the pull request still had. A session that worked on
  several pull requests is split between them. (#50)
- **Codex sessions have a cost.** It is an estimate from their tokens at list prices, marked as
  an estimate. (#47)
- **Survival at fixed ages.** How many of an agent's lines are still there 1, 7 and 30 days
  later, and how many of a pull request's lines are left after it merged. (#45)
- **Pull requests are matched again as their sessions arrive**, so a session uploaded after the
  pull request was opened still counts. A line common to many files goes only to a session that
  wrote other lines of the pull request. (#43)
- **`cargo install sessionly`.** The CLI is on [crates.io](https://crates.io/crates/sessionly).
- The GitHub Action reports a pull request's lines after it merged, and skips pull requests
  from forks. (#45, #49)
